# Steam Inspector: 朝鮮 프로토콜 (Joseon Protocol)

> **좌견착이냐, 우견착이냐 — 되돌릴 수 없는 한 번의 선택이 모든 엄폐를 바꾼다.**

조선 스팀펑크 암행어사 레일 슈터. 타임크라이시스식 "숨으면 살고, 나가야 이긴다" 리듬 위에,
**게임 시작 시 단 한 번 선택하는 견착 방향**이 모든 엄폐 모서리의 유불리를 결정하는 것이 핵심 훅이다.

**OpenAI Game Builders Seoul (Track 1) 출품작** · PC · 마우스 전용 · Chrome/Edge 권장 · 사운드 켜기 권장

## 조작법

| 입력 | 기능 |
|---|---|
| 마우스 | 조준 (절대좌표, 라이트건 방식) |
| **좌클릭** | 사격 (홀드 시 연사) |
| **Space / 우클릭 홀드** | 견착 노출 — **놓으면 즉시 엄폐 (숨으면 명중탄 100% 회피)** |
| R | 재장전 (엄폐 경유 · 엄폐 중엔 자동 재장전) |
| 1 · 2 · 3 | 무기 전환 (영천 장총 / 집경 카빈 / 천마도 의식총) |
| F | 회복 탕약 · C | 연막 캡슐 |
| Q | 궁극기 — 증기 폭격 지원 (**개활지 전용**) |
| Esc | 일시정지 · M | 음소거 |

## 견착 시스템 (핵심 훅)

- 시작 시 **마패 수여식**에서 좌/우 견착을 1.5초 홀드로 확정 — **이번 출정 동안 변경 불가** (변경 UI 자체가 없음).
- 견착과 같은 쪽 모서리 = **유리**: 노출 30% · 엄폐 복귀 100ms. 반대쪽 = **역견착**: 노출 65% · 복귀 220ms — **120ms 더 일찍 숨어야 산다.**
- 경고(트레이서 비행 1.0초)는 견착과 무관하게 평등 — *정보는 평등, 실행만 불리*. 숨은 확률 보정 없음(결정론).
- 역견착의 물리적 진실: 사선이 자기 엄폐물에 막히면 크로스헤어가 회색 ✕ (탄약 미소모).
- 보상: 역견착 노출 킬 = 점수 ×1.5 + 궁극기 게이지 ×1.5.
- 공정성: 레벨의 좌피크 2 · 우피크 2 · 중립 3 — 시작 화면에 고지되며 부팅 시 실데이터와 대조 검증된다.

## 시스템 각주

- **명중탄 규칙 (Time Crisis 문법)**: 잡졸(화승병)의 사격은 전부 연출탄. 위협은 **별기군 사수(붉은 띠)** 의 명중탄뿐 — 붉은 오라 + 경고음 + 가시 발광 트레이서로 반드시 예고된다. 임팩트 순간 완전 엄폐면 무효.
- **탄약**: `탄창/예비` 표기. 재장전량 = min(탄창최대 − 현재, 예비)를 예비에서 정확히 차감 (예: 20/200 재장전 → 40/180). 레일 이동 중 전 무기 완전 재장전. *(원 기획의 "탄창 0 자동 재장전"은 TC 엄폐-재장전 문법으로 개변, 탄종 3종은 무기 3종 역할로 통합.)*
- **궁극기**: 필드가 `open`일 때만 사용 가능(광화문 광장, 그리고 보스전 막판 천장 붕괴 후). `close`에서는 게이지 보존.
- 사망 시 현 노드 이어하기 무제한 (해당 구간 점수 절반). 최종 등급: 어사 장계 **수·우·미·양·가**.

## 실행

정적 파일이라 서버만 있으면 된다:

```bash
python -m http.server 8123
```

→ http://localhost:8123 · 디버그: `?hand=R&debug=1&stop=S3&god=1&timescale=2` 등 (debug.js 참조)
