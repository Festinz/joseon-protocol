# Steam Inspector: 朝鮮 프로토콜 (Joseon Protocol)

> **밤의 경복궁, 증기 요괴가 점거한 궁을 어사 혼자 되찾는다.**

조선 스팀펑크 **1인칭 슈터**. 자유 이동으로 광화문에서 근정전까지 밀고 올라가며,
장총·산탄총·활·환도를 갈아 쥐고, 몸을 기울여 모서리를 훔쳐보고, 회피로 총알을 흘리고,
마지막엔 신기전을 하늘에 쏘아 올린다.

**OpenAI Game Builders Seoul (Track 1) 출품작** · PC · 키보드+마우스 · Chrome/Edge 권장 · 사운드 켜기 권장

## 조작법

| 입력 | 기능 |
|---|---|
| **WASD** | 이동 · **Shift** 질주 · **C** 웅크리기(은신) |
| **마우스** | 시점 · **좌클릭** 사격 |
| **우클릭** | 무기에 따라 갈린다 — 총기는 **조준(ADS)**, 환도는 **강공** |
| **Ctrl** | **회피 스텝** — 누르고 있는 방향으로, 무입력이면 뒤로. 스텝 앞구간 무적 |
| **Z / X** | 좌 / 우로 몸 기울이기 (견착과 같은 쪽이 빠르고 깊다) |
| **1 2 3 4** | 무기 직접 선택 · **Space** 탭 = 순환, 홀드 = 무기 휠 |
| **R** | 재장전 · **F** 수류탄 투척 · **T** 회복 탕약 |
| **E** | 암살 (인지하지 못한 적의 배후에서) |
| **Q** | 궁극기 — **신기전 일제사격** (개활지 전용) |
| **Esc** | 일시정지 (포인터 잠금 해제) · **M** 음소거 |

## 무기 4종

| | 역할 | 탄창/예비 | 특징 |
|---|---|---|---|
| **영천 장총** | 중·원거리 주력 | 6 / 60 | 정밀 단발. 약점 ×2 |
| **조선 산탄총** | 근거리 폭발력 | 5 / 30 | 펠릿 8발. 3m 72뎀 → 20m 5뎀. 밀집에 한 발이면 여럿이 맞는다 |
| **흑각궁** | 은신 저격 | 1 / 3 | **무소음** — 쏴도 경보가 울리지 않는다. 60뎀 |
| **환도** | 근접 | — | 좌클릭 경공(34) · **우클릭 강공** — 150° 부채꼴 **전원** 타격 + 0.7초 경직 |

## 견착 — 시작할 때 한 번, 되돌릴 수 없다

출정 전 **마패 수여식**에서 좌/우 견착을 1.5초 홀드로 확정한다. 이번 판 내내 바꿀 수 없다
(바꾸는 UI 자체가 없다). 견착과 **같은 쪽으로 기울이면** 빠르고 깊게 내다볼 수 있고,
**반대쪽은 느리고 얕다.** 대신 역견착으로 잡은 적은 점수와 궁극기 게이지를 1.5배로 쳐준다.

정보는 평등하다 — 명중탄 경고는 견착과 무관하게 똑같이 온다. 불리한 것은 실행뿐이다.

## 이 게임의 규칙

**맞는 총알은 예고된다.** 화승병·팽배수의 사격은 전부 연출탄(데미지 0)이다.
실제로 아픈 것은 **별기군 사수**(붉은 어깨띠)의 명중탄뿐이고, 그것은 붉은 오라 + 경고음 +
발광 트레이서 1초 비행으로 반드시 예고된다. 피하는 법은 셋 — **이동**으로 착탄점을 벗어나거나,
**엄폐물**로 사선을 끊거나, **Ctrl 회피**의 무적으로 흘리거나.

**은신.** 웅크리면 인지 범위가 7m → 2.8m로 줄어든다. 인지하지 못한 적의 배후 1.8m에서 **E**로 암살.
흑각궁은 무소음이라 쏴도 경보가 안 뜬다.

**궁극기는 개활지에서만.** 신기전은 하늘이 뚫린 곳에서만 부를 수 있다. 실내에서는 게이지가 보존된다.
발사되면 **살아있는 적 수에 맞춰 로켓이 배분된다** — 1명이면 3발을 한 명에게, 3명이면 각각 1대씩.

**사망해도 현 구역에서 무한 재시작** (해당 구간 점수 절반). 최종 등급은 어사 장계 **수·우·미·양·가**.

## 여정

광화문 광장 → 관문 통로 → 경복궁 회랑 → 근정전 앞뜰 → 근정전 보스룸

- **사또** (근정전 앞뜰 중간보스) — 기계 외골격을 두른 탐관오리.
  근접 3연격 · 회전 후려치기 · 진천뢰 3연발. 거리마다 답이 다르다.
- **해태** (최종 보스) — 궁을 삼킨 증기 신수.
  가슴 코어가 **열릴 때만** 제대로 들어간다. 물어뜯기 · 꼬리 후리기 · 증기 브레스 ·
  체력이 깎이면 포효와 함께 **3중 확장 링**을 터뜨린다. 그때는 멀리 물러서는 것 말고 답이 없다.

## 실행

정적 파일이라 서버만 있으면 된다.

```bash
python scripts/devserver.py
```

→ http://localhost:8123

디버그 파라미터: `?hand=R&debug=1&god=1&zone=Z5&timescale=2` 등 (`src/debug.js` 참조).
`debug=1`이면 화면 좌상단에 fps·드로우콜·삼각형 수가 뜬다.

## 만든 방식

빌드 스텝이 없다. Three.js를 로컬 벤더링하고 바닐라 ES Modules + importmap으로 굴린다.
**폴더가 곧 제출물**이다 — 번들러 없음, 의존성 설치 없음.

- **Claude Code** — 설계·구현 주도. 멀티에이전트 리서치/설계/적대검증 → 그레이박스 → 에셋 스왑
- **Codex CLI** — 전투 코어 코드 리뷰 / 버그 헌트 (로그: `docs/codex/`)
- **Gemini 3 Pro Image (나노바나나 Pro)** — 뷰모델·컷씬·UI 아트.
  기존 아트를 레퍼런스로 넣어 손·재질·화풍을 통일했다
- **Meshy** — image/text-to-3D → 리깅 GLB. 텍스처는 1024 JPEG로 압축 (배포 51MB → 26MB)
- **사운드** — WebAudio 실시간 합성. 샘플 파일 0개
- **텍스처** — 캔버스 절차 생성
- 에셋 레지스트리(`src/assets.js`)가 절차적 모델을 먼저 세우고 GLB가 도착하면 무중단으로 갈아 끼운다.
  **AI 에셋이 하나도 없어도 게임은 끝까지 돌아간다.**
