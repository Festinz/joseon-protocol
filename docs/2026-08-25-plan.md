## 2. 게임 컨셉 & 핵심 메커니즘

### 2.1 견착 선택 의식 (마패 수여식) — 게임당 1회, 영구
1. 어명 두루마리 → 마패 낙인 연출 (스킵 가능)
2. 좌/우 **톱다운 다이어그램 카드**: 유리 모서리(초록, 노출 30%) vs 불리 모서리(주황, 노출 65%)를 그림으로 사전 고지
3. **공정성 고지**: "이 길에는 좌피크 N곳 · 우피크 N곳 · 중립 N곳" (실데이터와 부팅 assert로 일치 보증)
4. **LMB 1.5초 홀드로 확정** (오클릭 방지 + 의식의 무게감) → `Object.freeze` — 변경 UI 자체가 없음. 새 출정만이 유일한 변경 수단.

### 2.2 엄폐 & 노출 (Time Crisis 페달 문법)
- **Space/RMB 홀드 = 견착 노출·사격 가능, 릴리스 = 즉시 엄폐 복귀** ("놓으면 안전" — 패닉 실패가 곧 생존)
- 판정 한 줄: `favorable = (coverEdge === hand)`

| | 노출 | 카메라 오프셋 | 팝아웃 | **스냅인** | 히트박스 폭 |
|---|---|---|---|---|---|
| **유리 견착** | 30% | 0.25m | 120ms | **100ms** | 0.35m |
| **역견착** | 65% | 0.55m | 240ms | **220ms** | 0.70m |
| **중립(TOP, 낮은 엄폐)** | 50% | 상단 0.45m | 180ms | 160ms | 0.55m |

- **명중탄 판정은 결정론**: 임팩트 순간 완전 엄폐(COVERED)면 100% 무효, 아니면 −25. 경고~임팩트 반응창(트레이서 비행 1.0s)은 견착 무관 동일 — **"정보는 평등, 실행만 불리"**. 유효 반응창 유리 900ms vs 역견착 780ms → **120ms 더 일찍 숨어야 산다**. 숨은 확률 보정 절대 금지.
- **4채널 피드백**: ① 스냅인 지연 ② 카메라 오프셋(몸이 크게 나가는 체감) ③ **어깨 오리진 레이캐스트** → 역견착 시 모서리 사선이 자기 엄폐물에 막힘(크로스헤어 회색 ✕, 탄약 미소모) — 참고 영상의 물리적 진실 그대로 ④ HUD 노출 미터 + 피크 방향 배지(초록▶/주황◀).
- **역견착 보상**: `!favorable` 노출 킬 = 점수 ×1.5 + 궁 게이지 획득 ×1.5 (고위험 고수익 — 순수 벌 방지).
- 피격 리캡 1줄: 「역견착 노출 중 피격 −25」 — 죽음의 원인을 시스템이 설명.
- peekSide enum: `'L' | 'R' | 'TOP' | 'DUAL'` (DUAL = 같은 기둥에 L/R 노드 겹침 + A/D 전환 — 판정 코드 단일 경로 유지).

### 2.3 명중탄 프로토콜 (TC 이분법 — Combat gate 요건)
- **잡졸 사격은 전부 연출탄(데미지 0).** 플레이어를 맞추는 것은 텔레그래프된 명중탄뿐.
- 명중탄 4중 텔레그래프 (하나라도 빠지면 불합격): 사수 붉은 아웃라인 + 전용 경고음 + 「위험!」 마커/비네트 + **가시 발광 트레이서 1.0s 비행**.
- 투척물은 포물선 + **공중 격추 가능** (숨기 vs 격추 선택지).

### 2.4 무기·탄약 (PPTX `{0}/{1}` 규칙 정확 구현)
| | 영천 장총 (1) | 집경 카빈 (2) | 천마도 의식총 (3) |
|---|---|---|---|
| 탄창/예비 | 6 / 60 | 8 / 48 | 1 / 3 |
| 데미지 (약점 ×2) | 10 | 6 | 60 |
| 발사 간격 | 330ms | 180ms | 800ms |
| MVP 지위 | **기본** | 승격 ① | 승격 (보스 피날레) |

- 재장전: `장전량 = min(MaxMag−현재, 예비)`, 예비에서 정확히 차감 (20/200→40/180). **엄폐 400ms 후 자동 재장전 600ms** (TC 문법). 레일 이동 중 전 무기 완전 재장전.

### 2.5 궁극기 — 증기 폭격 지원 (PPTX open/close 규칙)
- 게이지: 명중 1 / 킬 4 / 약점 +3 / 격추 5, 역견착 배율 ×1.5. 감소 없음.
- **open 필드 전용** (광화문 광장, 보스 3페이즈 천장 붕괴 후). close에서는 자물쇠 아이콘 + 게이지 보존 → "아껴둔 한 방" 서사.
- MVP는 심플판(플래시+전멸+보스 150), 승격 시 시네마틱(무전→비행선 그림자→순차 착탄 5발).

### 2.6 아이템 (휠 제거 — 2종 직결 키)
- **F = 회복 탕약(+40, 최대 2)** [MVP] · **C = 연막 캡슐(4s 명중탄 정지)** [승격]. 휠은 4종+ 전제 설계라 2종 축소판에서는 직결 키가 원 의도(빠른 사용)에 더 충실.

### 2.7 점수 & 장계
- 킬 100 / 약점 200 / 격추 150 / 콤보 ×2@8히트·×4@16히트(빗나가면 리셋) / 구역 보너스 = 명중률×10 + 잔여초×50 + 노데미지 2000.
- 엔딩: 어사 장계 두루마리 — 조선식 5등급 **수/우/미/양/가** [승격; MVP는 점수+한줄평]. 결과에 견착·역견착 킬 수 표기.
- 사망 시 현 노드 이어하기 무제한(구간 점수 ×0.5) — 심사위원 완주 보장 (Playability).

| # | 스톱 | field | 피크 | 내용 | 시간 |
|---|---|---|---|---|---|
| S1 | 드랍지점 | open | TOP 중립 | 튜토리얼: 팝아웃·사격·자동장전. 명중탄 없음 | 0:40 |

| S3 | **폭풍의 관문** | close | **R → L 강제 스왑** | **핵심 훅 선언문** — 참고 영상의 문틈 견착. w1 좌문설주(peek R) → 보일러 폭발 → 우문설주(peek L). 양 견착이 정확히 1회씩 유리/불리 경험. 구현은 "노드 교체"(레일 코드 재사용) | 1:15 |

### 3.1 고붕이 (쇠 먹는 불가사리형 초대형 증기 자동인형) — MVP 축소판
- **P1 (중립 TOP 커버)**: 어깨 포탑 4문(각 HP 25, 개별 파괴) 로테이션 명중탄 2.5s. 가슴 폐쇄(회색 ✕ 피드백).

## 4. 기술 아키텍처

- **스택**: Three.js **로컬 벤더** + 바닐라 ES Modules + importmap. **빌드 스텝 제로** (Vite 안 씀 — 마감 1시간 전 빌드 실패 리스크 원천 제거). 폴더 = 제출물.
- **파일 구조**: `index.html + src/{main, config, state, input, rail, cover, combat, weapons, enemies, boss, ui, vfx, audio, assets, leveldata, debug}.js` — **config.js가 모든 수치의 단일 진실** (문서 간 수치 드리프트 종결, 검증 지적 반영).
- **카메라 리그**: `railDolly > coverRig > shoulderRig > camera+viewmodel`. 견착은 딱 2곳에만 스며듦: shoulderRig.x = ±0.22m, favorable 판정. 뷰모델은 2-패스 clearDepth 렌더. **미러 규칙**: 절차 메시만 `scale.x=-1` 허용, GLB는 원본 유지+오프셋 반전만 (검증 지적 반영).
- **에셋 레지스트리**: `instantiate(id)` = 절차적 버전 즉시 생성 → GLB 실존 시 무중단 스왑 → 404는 조용히 무시. **코딩이 에셋을 절대 기다리지 않는다.**
- **적**: 리깅 없음 — 절차적 조립(갓=Cylinder+Torus, 두루마기=Capsule+Cone) + 피벗 서브그룹 모션 + 12개 풀 + 지오메트리 병합(액터당 드로우콜 2).
- **성능 예산**: ≤250k tri, 드로우콜 ≤150, 그림자 맵 0, PointLight ≤4, 공유 머티리얼 7개. `renderer.info` 상시 노출.
- **디버그 훅 (H2에서 레일과 동시 구현)**: `?stop= ?hand= ?god= ?ult= ?timescale= ?snap= ?exp= ?perf=low` + K(웨이브 전멸)·N(다음 노드) 치트. 사용자 혼자 손맛 튜닝 반복 가능.
- **오디오**: WebAudio 합성 SFX 5종(다운로드 0, 저작권 0) + 절차 드론 앰비언트(컷 불가 폴백). 파일 BGM만 컷 대상.
- **자잘한 필수**(검증 반영): Esc 일시정지(견착 정보 표기), blur 시 자동 일시정지+강제 엄폐, M 음소거, localStorage 최고점, "PC·마우스 권장" 안내.
